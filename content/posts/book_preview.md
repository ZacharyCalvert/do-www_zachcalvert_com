## Designing, Modeling, and Securing RESTful APIs

I started a REST API design book in 2017 while working at BNSF and shelved the project to focus on learning new languages such as golang and DevSecOps technologies including GitHub Actions.  After departing BNSF, I ended up designing APIs at Toyota, Signify Health, and at McKesson.  Each new role ended up with me leading the same conversations and discussing the same topics regarding API design, architecture, and security.

I believe that my book still has a place on the shelf, even after the AI revolution.  I'd like to share a preview of [Designing, Modeling, and Securing RESTful APIs](/DMSR_preview.epub) and hope that it helps engineers in their design approach.  

The project originally started as a LaTeX document with compilation using GitHub Actions at [RESTBook](https://github.com/ZacharyCalvert/restbook/tree/532c3b5649bf3f5a9a0e4ebd655a03a0945c6525), but I reworked it using Scrivener so I could compile right to an e-book format.  Unfortunately, I was unable to get an audience with O'Reilly and have decided to self-publish straight to Kindle and Nook.  I aim to publish by end of 2026.
